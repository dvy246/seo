# SerpCraft Pricing

## Free Tier
- Price: $0/month
- Limits: 10 URL comparisons/month, 5 saved baselines, manual runs only
- Features: Release Diff (staging vs prod, migration, regression), Markdown export, 12 critical SEO checks
- Support: Community (GitHub Discussions)

## Pro Tier
- Price: $29/month (billed annually) | $35/month (billed monthly)
- Limits: 100 URL comparisons/month, unlimited saved baselines, scheduled monitoring, API access
- Features: Everything in Free + GitHub Action integration, email/webhook notifications, regression history (90 days), priority support
- Support: Email (24hr response)

## Team Tier
- Price: $79/month (billed annually) | $95/month (billed monthly)
- Limits: 300 URL comparisons/month, 3 seats, shared workspaces, team baselines
- Features: Everything in Pro + shared baseline library, team notifications, audit log, SSO (SAML/OIDC)
- Support: Priority email + Slack connect

## Enterprise
- Price: Custom — contact sales@serpcraft.app
- Limits: Unlimited comparisons, unlimited seats, custom retention, dedicated infrastructure
- Features: Everything in Team + SLA (99.9%), custom checks, on-premise deployment option, dedicated success manager
- Support: 24/7 phone + Slack + dedicated channel

## What's Included in All Tiers
- 12 Critical SEO Checks: HTTP/redirects, indexability, canonicals, URL parity, sitemaps, initial HTML, metadata, social assets (OG/X), JSON-LD, hreflang, robots.txt, content signals
- Evidence-First Reports: No scores — exact before/after evidence, consequence, suggested fix
- Three-Section Classification: 🔴 Release Blockers | 🟡 Warnings | 🟢 Informational
- Export Formats: Markdown, HTML, JSON
- Browser-First: No signup required for single comparisons
- Privacy: Your URLs never stored on our servers (Free/Pro use local browser storage)

## Billing
- No credit card required to start Free tier
- 14-day free trial for Pro/Team (no card required)
- Cancel anytime, keep access until period ends
- VAT/GST handled automatically via Stripe

## Fair Use
Free tier intended for individual developers and small sites. Automated high-volume usage (CI on every commit for large monorepos) requires Pro/Team. We'll reach out if usage patterns suggest upgrade — no surprise blocks.
